Modelo Relacional - Esquema de Tablas

PERSONA
DNI VARCHAR(20) PRIMARY KEY
Nombre VARCHAR(100) NOT NULL
Apellidos VARCHAR(150) NOT NULL
Tipo_Persona ENUM('PROFESOR', 'ALUMNO') NOT NULL
PROFESOR
DNI VARCHAR(20) PRIMARY KEY
DNI FOREIGN KEY → PERSONA(DNI)
Varita VARCHAR(200) NOT NULL
CONSTRAINT: UNIQUE(DNI)
ALUMNO
DNI VARCHAR(20) PRIMARY KEY
DNI FOREIGN KEY → PERSONA(DNI)
Código_Casa VARCHAR(10) NOT NULL
Código_Casa FOREIGN KEY → CASA(Código_Casa)
CONSTRAINT: UNIQUE(DNI)
CASA
Código_Casa VARCHAR(10) PRIMARY KEY
Nombre_Casa VARCHAR(50) NOT NULL
DNI_Tutor VARCHAR(20) NOT NULL UNIQUE
DNI_Tutor FOREIGN KEY → PROFESOR(DNI)
CHECK: Nombre_Casa IN ('Gryffindor', 'Slytherin', 'Hufflepuff', 'Ravenclaw')
IMPARTE_CLASE
DNI_Profesor VARCHAR(20)
DNI_Alumno VARCHAR(20)
PRIMARY KEY (DNI_Profesor, DNI_Alumno)
DNI_Profesor FOREIGN KEY → PROFESOR(DNI)
DNI_Alumno FOREIGN KEY → ALUMNO(DNI)
Observaciones TEXT NULL
GANADOR
Código_Casa VARCHAR(10)
Año INTEGER
PRIMARY KEY (Código_Casa, Año)
Código_Casa FOREIGN KEY → CASA(Código_Casa)
Puntos INTEGER NOT NULL
Premio VARCHAR(200) NOT NULL
CHECK: Puntos > 0
MORTIFAGO
DNI_Profesor VARCHAR(20) PRIMARY KEY
DNI_Profesor FOREIGN KEY → PROFESOR(DNI)
Código_Preso VARCHAR(50) NOT NULL UNIQUE
Años_Preso INTEGER NOT NULL
CHECK: Años_Preso > 0
CONSTRAINT: UNIQUE(DNI_Profesor)

📊 Resumen de Integridad Referencial

Claves Primarias (PK):
  • PERSONA: DNI
  • PROFESOR: DNI
  • ALUMNO: DNI
  • CASA: Código_Casa
  • IMPARTE_CLASE: (DNI_Profesor, DNI_Alumno)
  • GANADOR: (Código_Casa, Año)
  • MORTIFAGO: DNI_Profesor
Claves Foráneas (FK):
  • PROFESOR.DNI → PERSONA.DNI
  • ALUMNO.DNI → PERSONA.DNI
  • ALUMNO.Código_Casa → CASA.Código_Casa
  • CASA.DNI_Tutor → PROFESOR.DNI
  • IMPARTE_CLASE → PROFESOR + ALUMNO
  • GANADOR.Código_Casa → CASA.Código_Casa
  • MORTIFAGO.DNI_Profesor → PROFESOR.DNI
⚠️ Restricciones Críticas de Negocio:
  • Participación obligatoria de ALUMNO: Todo alumno debe tener al menos un registro en IMPARTE_CLASE (trigger o constraint)
  • Tutor único por casa: CASA.DNI_Tutor es NOT NULL y UNIQUE
  • Casa obligatoria: ALUMNO.Código_Casa es NOT NULL
  • Exclusividad Profesor-Alumno: Un DNI solo puede existir en PROFESOR o en ALUMNO, no en ambos
  • Cobertura total: Todo DNI en PERSONA debe aparecer en PROFESOR o ALUMNO (trigger)
